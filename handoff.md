Folder windows + Desktop icons can use StarDust; taskbar/Start stay Windows. Contract: [StarDust UI.md](StarDust%20UI.md). Drive tools: [desktop-drive.md](desktop-drive.md). Binaries: `fs-viz`, `stardust-open` (HKCU folder verb trampoline), `stardust-guard` (HKCU Run + tray + Ctrl+Shift+F12). Login: HKCU Run `StarDustUI` = `fs-viz --desktop` while StarDust UI is on (removed on Windows UI). Desktop window is native **WebView2** (`StarDustHost`) over the work area — not Edge `--app=`. Browser accelerators, page zoom, swipe-back, and the Edge context menu are off. Loader: `crates/fs-viz/webview2-loader/WebView2Loader.dll` next to `fs-viz.exe`. Host: `stardust-view.exe` (`test = false` so GNU `cargo test` does not load that COM binary). CSS `html.shell-desktop` drops the inner cosmos glow. Mode/health: `%APPDATA%/StarDust/ui-mode.json`, `ui-health.json`, `ui-guard.log`. Failover stays on Windows UI until the user re-enables StarDust. Open in Explorer uses the `explore` verb. No WorkerW. GNU host: `std::net`, no tokio.

Live source is snapshot **`3c2a4ae`**. The post-snapshot UI is on **`archive/ui-peek-power`** (reference only — do not copy). Interview list: [ui-delta.md](ui-delta.md).
