# Handoff

## Windows Explorer/Desktop UI

Folder windows + Desktop icons can use StarDust; taskbar/Start stay Windows. Contract: [StarDust UI.md](StarDust%20UI.md). Binaries: `fs-viz`, `stardust-open` (HKCU folder verb trampoline), `stardust-guard` (HKCU Run + tray + Ctrl+Shift+F12). Login: HKCU Run `StarDustUI` = `fs-viz --desktop` while StarDust UI is on (removed on Windows UI). Desktop window is a native **WebView2** host (`StarDustHost`) covering the work area — not Edge `--app=` (Chromium caption clip is only a leftover fallback). Browser accelerators, page zoom, swipe-back, and the Edge context menu are off so in-app keys/menus run. Loader DLL: `crates/fs-viz/webview2-loader/WebView2Loader.dll` copied next to `fs-viz.exe`. Host process: `stardust-view.exe` (WebView2; `test = false` so GNU `cargo test` does not load that COM binary). CSS `html.shell-desktop` drops the inner cosmos glow. Mode/health: `%APPDATA%/StarDust/ui-mode.json`, `ui-health.json`, `ui-guard.log`. Failover stays on Windows UI until the user re-enables StarDust. Open in Explorer uses the `explore` verb. No WorkerW. GNU host: still `std::net`, no tokio.
